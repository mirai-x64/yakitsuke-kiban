# 焼け付くほど強くなる基板デッキ

電子回路基板を題材にした、単一HTML・依存ゼロのデッキ構築ローグライク。
`index.html` をブラウザで開くだけで遊べる。

## 遊び方

1. 「ランを開始」を押すと1体目の故障との戦闘が始まる。
2. 毎ターン、エネルギー3を使って手札からカードを場に出す。カードは山札から5枚引かれ、ターン終了時に捨て札へ送られる。
3. 相手(故障)のHPを0にすれば勝利、自分のHPが0になれば敗北。
4. 故障は毎ターンの行動(次に与えてくるダメージ)を事前に予告する。不意打ちはない。
5. 各故障には耐性属性(与ダメージ半減)と弱点属性(与ダメージ1.5倍)があり、戦闘開始時に表示される。
6. 勝利するたびに3枚からカードを1枚獲得できる(獲得しなくてもよい)。獲得したカードは使用回数0から始まる。
7. 故障3体を倒せばラン終了。

## ひねり: 使い込むほど育つカード

**同じ1枚のカード(コピーではなく、その物理的な1枚)を繰り返し場に出すと、そのカードの効果が永続的に強化される。**

- 3回使用: 効果+50%
- 6回使用: さらに+50%(合計+100%、つまり2倍)

新しく獲得したカードは使用回数0から始まるため、育てるには同じカードを実際に握り続けて何度も出す必要がある。

## 対抗圧: 属性の3すくみ

カードは電流(⚡)・電圧(🔌)・熱(🔥)の3属性を持つ。故障側もこの3属性に対する耐性・弱点を持ち、互いにじゃんけんの関係になっている。

| 故障 | 耐性(半減) | 弱点(1.5倍) |
|---|---|---|
| 短絡 | 電流 | 電圧 |
| 過熱 | 熱 | 電流 |
| 絶縁劣化 | 電圧 | 熱 |

1つの属性に全投資すると、3戦のうち1戦は大活躍、1戦はほぼ互角、1戦は耐性で半減という結果になる。平均倍率は分散投資と同じ1.0倍だが、内訳の分散が生まれるため「どこまで1属性に集中し、どこで妥協するか」という判断が実在する。

## カード一覧(8種)

| カード | 種別 | コスト | 効果 |
|---|---|---|---|
| 抵抗 | 攻撃(電流) | 1 | 6ダメージ |
| コンデンサ | 攻撃(電圧) | 1 | 6ダメージ |
| サーミスタ | 攻撃(熱) | 1 | 6ダメージ |
| 基板シールド | 防御 | 1 | ブロック8 |
| コイル | 強化 | 1 | 1枚ドロー(強化時は2枚+エネルギー) |
| バッテリー | 強化 | 0 | エネルギー+1(強化時+2) |
| オペアンプ | 強化 | 1 | 次の攻撃カードのダメージ+50%〜100% |
| ヒューズ | 強化 | 1 | 故障の予告ダメージ分をブロック |

## 開発メモ

`index.html` 単体で完結している(ビルド不要、外部依存なし)。ロジックはインラインの `<script>` に全て収めてある。
